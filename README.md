## My Journey
#### 2018
My introduction to programming was as a kid in 2018, using Swift Playground on the iPad.
A few months later, I discovered AppleScript, which really got me interested in coding.
I could automate things on my computer and even make some “fake” viruses just for fun.

#### 2020
About two years later, I discovered Discord bots and started creating them with BotGhost.
I quickly ran into its limitations and switched to building custom bots using `discord.js`.
This was also when I started learning **JavaScript** and got into programming my first few projects.

Between 2020 and 2022, I created over **40+ custom Discord bots for different servers**,
while learning concepts like databases, web development and more!

#### 2022
One of those projects was **a small ticket bot** that I eventually decided to publish on Github.
This project became [**Open Ticket**](https://www.github.com/open-discord-bots/open-ticket), which has grown into one of the most advanced and customisable open-source Discord ticket bots ever created!
Funny enough, its **popularity was never really planned**. In the beginning, Open Ticket was quite basic, had plenty of bugs, and wasn't nearly as customisable as it is today. Still, I kept working on it, adding new features and improving it over time. Eventually, it grew into the project it is today.

#### 2023
Since 2023, I've also been working on several side projects including: [**Math Master**](https://github.com/DJj123dj/math-master) the calculator bot, some NPM Packages like [**Discord Alt Detector**](https://www.npmjs.com/package/discord-alt-detector), [**Formatted Json Stringify**](https://www.npmjs.com/package/formatted-json-stringify) and my dream project **LiveControl**, a DMX lighting control system for DJs.
Working on these projects has helped me learn new languages and technologies, including HTML, PHP, TypeScript, CSS, Lua, Python, GDScript, Electron, SQL, ...

#### 2025
In 2025-2026, I started focussing on larger projects and major updates including [**Open Ticket 4.0**](https://www.github.com/open-discord-bots/open-ticket), **LiveControl v2** and [**TeamPlayer**](https://www.team-player.be) a sports club management system.  
Whenever I get new ideas I still experiment with some smaller projects and tools.

#### Long Term Goals
Looking ahead to 2027, I plan to keep maintaining [**Open Ticket**](https://www.github.com/open-discord-bots/open-ticket), work on new plugins and try to launch [**HTML Transcripts v3**](https://t.dj-dj.be).
I will also continue to develop **LiveControl v2** and [**TeamPlayer**](https://www.team-player.be).
I might also release some new npm packages along the way.

My long-term goal is to create **Open Moderation**, a Discord moderation bot with the same level of customisation and flexibility as Open Ticket.

## Top Projects
### [Open Ticket](https://www.github.com/open-discord-bots/open-ticket)
The most advanced self-hosted discord ticket bot with HTML transcripts,  
plugins, questions, claiming, statistics, pterodactyl/docker support & more!

### [Open Discord: Plugin Ecosystem](https://www.github.com/open-discord-bots/plugins)
Open Ticket has been built in such a way that it has next-level support for plugins!  
That's why we've built a collection of awesome plugins to supercharge Open Ticket.

### [Discord Alt Detector (NPM)](https://www.npmjs.com/package/discord-alt-detector)
Discord Alt Detector is a tiny npm package to catch Discord Alt Accounts based on several parameters in their profile and behaviour.
It checks for username patterns, profile pictures, badges, their status and more!

### [Formatted Json Stringify (NPM)](https://www.npmjs.com/package/formatted-json-stringify)
Formatted Json Stringify is a small npm package which allows you use an advanced & customisable version of the JSON.stringify()!

### [Logbucket (NPM)](https://www.npmjs.com/package/logbucket)
A lightweight and customizable logging library for Node.js based on the log system of Open Ticket.  
It features beautiful logs with configurable colors, prefixes and a debugfile for permanent logs.

### [Apc Mini Mk2 (NPM)](https://www.npmjs.com/package/apc-mini-mk2)
An easy-to-use and feature-rich Node.js package for interacting with one or multiple Apc Mini's (Mk2) from Akai Professional.
Perfect for scripts, Electron apps, automation, smart home, music production, games, event lightning, ...

### [Math Master](https://github.com/DJj123dj/math-master)
A simple self-hosted calculator bot for discord.  
This project was made to test the new Discord interaction buttons.

### [Train Speed Limits (Factorio Mod)](https://mods.factorio.com/mod/train-speed-limits)
A mod for Factorio to limit trains to a certain speed within a signal block.  
Pretty useful if you respawn a lot because of crossing rails.

### [Improved Upgrade Planner (Factorio Mod)](https://mods.factorio.com/mod/improved-upgrade-planner)
A mod for Factorio which adds turrets, big power poles, substations and combinators to the upgrade planner.

### LiveControl
Real-time lightning software for DJ's with the ability to control DMX-powered lights. Just plug & play, no configuration required. Perfect for music-synced lightning!
(Private Project)

### [TeamPlayer](https://www.team-player.be)
User management software for sportclubs. Only available for known and registered sportclubs in Belgium.
